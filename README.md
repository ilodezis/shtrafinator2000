# Штрафинатор 2000

Внутренний инструмент CloudPayments для macOS. Он делает две рутинные вещи со штрафами за фрод:

- собирает уведомления об удержании штрафа в Word по строкам Excel-реестра;
- переименовывает PDF-сканы подписанных уведомлений по названию организации.

Всё считается на компьютере. Сети приложение не касается, распознавание сканов идёт через Apple Vision на устройстве.

## Установка

Скачайте `Shtrafinator_2000_macOS.pkg` из [последнего релиза](../../releases/latest) и запустите. Установщик кладёт приложение в «Программы» и снимает с него карантин: сборка подписана без сертификата Apple, и без этого Gatekeeper не дал бы её открыть.

Нужна macOS 14 или новее, Mac на Apple Silicon или Intel.

## Уведомления

Перетащите реестр `.xlsx` в окно, выберите папку для документов, укажите дату и подписанта, нажмите «Сгенерировать». Подписанта приложение запоминает до следующего раза. Если поле пустое, в документе останется место для ручного ввода.

Данные берутся с листа «Для соп-я», а если такого нет, с первого листа, в названии которого есть «соп». В работу идут только строки, где в колонке решения стоит «да».

Колонки ищутся по словам в заголовке первой строки, регистр и «ё/е» не важны.

| Колонка | Что ищется в заголовке | Если нет |
|---|---|---|
| Отчётный период | `отчетный` и `период` | ошибка |
| ИНН | `инн` | ошибка |
| Юрлицо | `юл` | ошибка |
| Фрод, руб. | `фрод` и `руб` | ошибка |
| Штраф | `штраф` | ошибка |
| Решение | `решение` | ошибка |
| Доля фрода | `% фрод` или `фрода от оборота` | ошибка |
| Директор | `директор`, `руководитель`, `гендир` или `фио` | заглушка |
| ОГРН | `огрн` | заглушка |
| Email | `email`, `e-mail` или `почта` | заглушка |

Суммы и проценты читаются и как числа, и как текст: «30 000,50» и «1,86%» подходят. ФИО директора ставится в дательный падеж. У ИП оно берётся из названия, у остальных из колонки директора. Склонение справляется с инициалами, двойными и несклоняемыми фамилиями и ФИО заглавными буквами. Шаблон свёрстан так, чтобы уведомление с длинным названием и суммой прописью помещалось на один лист A4 вместе с подписью.

Файл называется по организации. Кавычки из названия убираются (`ООО «Ромашка»` → `ООО Ромашка`), запрещённые в именах файлов символы заменяются на `_`.

## Сканы

Перетащите папку с PDF из принтера и запустите переименование. Приложение читает первую страницу: сначала текстовый слой PDF, а если его нет, распознаёт картинку. Название организации ищется в абзаце «Между…» или в шапке. Существующие файлы не перезаписываются, поэтому папку можно прогонять повторно.

## Сборка

Нужны macOS 14+ и Xcode 16 или новее. Ядро без интерфейса собирается и тестируется и на Linux.

```bash
swift test                      # тесты ядра
swift run Shtrafinator          # запуск из терминала
scripts/build-app.sh            # dist/Shtrafinator_2000.app, arm64 + x86_64
scripts/build-app.sh --pkg      # плюс установщик .pkg
```

Версия берётся из `VERSION` (по умолчанию `2.0.0`). Релиз собирается в GitHub Actions при пуше тега `v*`.

Шаблон уведомления лежит в `Resources/template.docx`: чтобы поменять текст письма, замените файл и пересоберите. Разбор `.xlsx` и сборка `.docx` написаны вручную поверх OOXML, из внешних зависимостей только [ZIPFoundation](https://github.com/weichsel/ZIPFoundation).

```
Sources/ShtrafinatorCore/   ядро: реестр, уведомления, сканы
Sources/Shtrafinator/       интерфейс на SwiftUI
Tests/                      тесты и фикстуры .xlsx
Resources/                  шаблон .docx и логотип
scripts/build-app.sh        сборка .app и .pkg
```
