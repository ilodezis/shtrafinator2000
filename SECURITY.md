# Security Policy

## Область применения

**Штрафинатор 2000** — внутренний инструмент компании CloudPayments для автоматизации подготовки документов. Данный документ предназначен для служб информационной безопасности при оценке рисков применения программы.

---

## Архитектура и поверхность атаки

Приложение является **изолированным нативным приложением для macOS** без каких-либо сетевых функций. Интерфейс построен на SwiftUI: встроенного браузера, веб-представлений (WebView) и среды выполнения Python в приложении нет.

| Характеристика | Значение |
|---|---|
| Тип приложения | Нативное десктопное приложение macOS (SwiftUI), без сервера |
| Сетевые подключения | **Отсутствуют** |
| Внешние API / сторонние сервисы | **Не используются** |
| Веб-представления и встроенный браузер | **Отсутствуют** |
| Среда выполнения Python | **Отсутствует** |
| Хранение данных | **Минимальное** — сохраняется только последнее введённое имя подписанта (см. ниже); файлы реестра и сканов, а также сгенерированные документы не кэшируются |
| Передача данных | **Нет** — данные не покидают рабочую станцию пользователя |
| Аутентификация / авторизация | **Не требуется** — нет пользовательских аккаунтов и паролей |
| Привилегии ОС | Стандартные права пользователя, без запроса прав администратора |

---

## Что делает приложение

1. Читает файл `.xlsx` с локального диска, предоставленный пользователем.
2. Формирует на основе данных из файла документы `.docx`.
3. Сохраняет документы `.docx` в указанную пользователем папку на локальном диске.
4. По запросу читает первую страницу PDF-сканов из выбранной пользователем папки и переименовывает файлы по названиям организаций. Существующие файлы не перезаписываются.
5. Завершает работу.

На этом весь цикл работы программы заканчивается.

---

## Хранение данных

* **Имя подписанта**: программа запоминает последнее введённое имя подписанта в пользовательских настройках приложения (`UserDefaults`) и предлагает его при следующем запуске. Это единственные данные, которые сохраняются между запусками. Значение хранится в профиле текущего пользователя macOS и никуда не передаётся.
* **Распознавание сканов**: текст PDF извлекается на устройстве с помощью встроенных фреймворков PDFKit и Vision (Apple). Данные для распознавания не отправляются во внешние сервисы.

---

## Что приложение не делает

- Не устанавливает сетевые соединения (исходящих и входящих запросов нет).
- Не обращается к базам данных, платёжным системам или банковской инфраструктуре.
- Не читает и не изменяет системные файлы и системные настройки macOS (кроме собственных пользовательских настроек приложения).
- Не запрашивает повышенных привилегий.
- Не собирает телеметрию и не отправляет аналитику.
- Не устанавливает фоновые службы или автозагрузку.

---

## Зависимости

Приложение использует открытые компоненты и системные фреймворки Apple:

| Компонент | Назначение |
|---|---|
| `ZIPFoundation` (Swift-пакет) | Распаковка и упаковка ZIP-контейнеров `.xlsx` и `.docx` |
| SwiftUI | Графический интерфейс (окно приложения) |
| PDFKit, Vision | Чтение текста PDF-сканов и распознавание текста на устройстве |

Все зависимости собираются в исполняемый файл приложения и не требуют установки стороннего ПО.
